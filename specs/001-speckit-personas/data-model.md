# Workflow Artifacts

No application models, database schemas, or persisted weather data change.

- **Profile**: Unique name, nonempty description, inherited repository
  instructions, domain scope, exclusions, criteria, evidence expectations.
- **Triage outcome**: Tier, affected surfaces, invoked or inline perspectives,
  compatibility risks; reassess when scope grows.
- **Feature**: Spec, plan, tasks, and review/test evidence; local active feature
  pointer is ignored by Git.
