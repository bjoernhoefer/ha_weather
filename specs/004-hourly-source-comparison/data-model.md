# Data Model: Hourly Source Comparison

## ProviderHourlyForecast

One hourly temperature forecast from one internet weather provider.

| Field | Meaning | Validation / invariant |
|---|---|---|
| `location_id` | Forecast location | Existing configured location |
| `provider` | Weather provider identifier | Non-empty existing provider identity |
| `target_time` | Absolute target hour | Canonical UTC ISO-8601 timestamp |
| `issued_at` | Time the forecast was retrieved | Canonical UTC ISO-8601 timestamp |
| `temperature` | Forecast temperature | Nullable Celsius value |

The identity key is `(location_id, provider, target_time)`. Keep the first forecast saved for a target hour independently for each provider. Do not create rows for target times at or before issue time. Retain up to 72 hours; do not migrate consensus-only values into provider rows.

## HourlyMeasurement

One hourly measurement from a configured outdoor Home Assistant sensor.

| Field | Meaning | Validation / invariant |
|---|---|---|
| `location_id` | Measurement location | Existing configured location |
| `target_time` | Absolute measured hour | Canonical UTC ISO-8601 timestamp |
| `source_id` | Stable measurement identity | Derived from Home Assistant `instance_id` and `entity_id`; not the display name |
| `instance_id` | Configured HA instance | Preserve identity for multi-instance installations |
| `entity_id` | Configured HA sensor | One entity per record |
| `source_name` | Human-readable sensor label | Configured name and instance name, otherwise entity ID |
| `temperature` | Hourly mean | Nullable Celsius value; omit row if no finite numeric data |

The identity key is `(location_id, source_id, target_time)`. A later observation refresh may update the same key. Retain up to 72 hours. Only outdoor HA measurements participate.

## HourlyComparison

An API/UI representation generated by matching a `ProviderHourlyForecast` and an `HourlyMeasurement` at the same location and UTC target hour.

| Field | Meaning |
|---|---|
| `target_time` | Shared UTC target hour |
| `provider` | Forecast source |
| `source_id`, `source_name` | HA measurement source |
| `forecast_temperature` | Nullable forecast in Celsius |
| `measured_temperature` | Nullable measurement in Celsius |
| `temperature_error` | Forecast minus measured value; null unless both exist |
| `absolute_temperature_error` | Absolute value of signed error; null unless both exist |
| `assessment` | `good` (≤1 °C), `check` (>1 °C and ≤2 °C), `large` (>2 °C), or null if values are incomplete |

Each output row is pair-specific; no provider consensus or sensor average substitutes for a source value.

## Retention and compatibility

The new archive tables are additive and created for existing SQLite files without rebuilding existing data. Existing consensus `hourly_predictions`, observations, daily forecast history, and provider scores remain unchanged. Existing consensus retention remains in place; each new table deletes target hours older than 72 hours.
