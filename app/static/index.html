Locations

Add a location by name; latitude/longitude are optional and improve the accuracy (e.g. the exact garden instead of the city centre). Without them the name is looked up with the Open-Meteo geocoding API, the time zone is detected automatically. Locations from the environment configuration cannot be deleted here.
